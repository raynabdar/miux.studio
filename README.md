# MIUX Studio

> Modern digital design and web development studio. High-impact interfaces, design systems, and web applications built for startups and fast-moving teams.

## Tech Stack

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/)
- **Type Safety**: [TypeScript](https://www.typescriptlang.org/)
- **Scheduling**: [Cal.com](https://cal.com/)

## Getting Started

First, install the dependencies:

```bash
pnpm install
```

Copy the environment example and configure your variables:

```bash
cp .env.example .env.local
```

Run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build for Production

```bash
pnpm build
pnpm start
```
